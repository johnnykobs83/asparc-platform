# Photography slots

The site is designed around strong athletic photography. Each slot below already has a branded
duotone fallback, so the site looks finished without photos – drop real images in with these exact
file names and they appear automatically (a dark overlay keeps text readable).

| File | Used on | Suggested shot |
|---|---|---|
| `hero.jpg` | Home hero, Contact | Athlete mid-sprint or powerful lift, landscape, subject on the right third |
| `sports-performance.jpg` | Sports Performance | Coached strength or speed session |
| `academy.jpg` | Performance Academy | Junior athletes training (with written parent/guardian photo consent) |
| `rehabilitation.jpg` | Rehabilitation | Controlled single-leg or return-to-run drill |
| `recovery.jpg` | Recovery & Massage | Massage table / recovery space |
| `performance-testing.jpg` | Testing | Only equipment ASPARC actually has |
| `founder.jpg` | Home & About | Portrait of John, 4:5 portrait crop |
| `about.jpg` | About, legal pages | Facility or team environment |

Guidelines: 2400px wide landscape (founder 1200×1500), JPG ~300–500 KB, real ASPARC athletes/venue
preferred. Use only photos you own or have licensed, and hold signed consent for anyone identifiable –
parent/guardian consent for anyone under 18. Don't show equipment or settings that imply services
ASPARC doesn't offer.
